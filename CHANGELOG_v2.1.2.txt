v2.1.2 — 시뮬레이션/보고서 팝업 UI

목적
- 본문 스크롤을 줄이고, '검토가능 사업방식' 영역에서 필요한 후속 검토를 바로 열도록 UI 재배치.

변경
1. 검토가능 사업방식 하단에 2개 실행 아이콘 추가
   - 우선순위 사업 시뮬레이션
   - 보고서 인쇄

2. 우선순위 사업 시뮬레이션
   - 전체화면에 가까운 대형 팝업으로 열림
   - 1·2·3순위 계획규모 검토를 팝업 내부에서 수행
   - 기반시설 / 순대지 / 용적률 / 연면적 / 세대수 기존 기능 유지
   - 팝업 내부만 스크롤
   - 자동순위 복원
   - 보고서 보기 버튼으로 보고서 팝업 전환

3. 보고서
   - 별도 보고서 미리보기 팝업
   - 검토데이터 JSON
   - 인쇄 / PDF 버튼 유지
   - 본문에는 보고서 미리보기 영역을 표시하지 않음

4. UX
   - 배경 클릭 또는 ESC로 팝업 닫기
   - 팝업이 열리는 동안 본문 스크롤 잠금
   - 모바일에서는 세로형 버튼 및 거의 전체화면 팝업

5. 성능
   - 검토가능 사업방식 판정이 갱신될 때 무거운 시뮬레이션 카드 전체를 매번 렌더링하지 않음.
   - 추천 1·2·3순위 데이터만 즉시 갱신.
   - 시뮬레이션 팝업을 열 때 계획안 UI 렌더링.

계산엔진
- v2.1.1의 기반시설/순대지/FAR/세대수 계산식은 변경하지 않음.
