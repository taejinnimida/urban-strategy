v1.5.0 — 컴팩트시티플랫폼 첫 화면 재구성

브라우저/창 제목
- 컴팩트시티플랫폼

첫 화면 의사결정 입력
- 목적사업
- 토지확보여부
- 의뢰·추진주체

검토가능 사업방식
- 8개 제도를 우측 상단에서 동시에 표시
- 우선검토 가능 제도: 진한 색
- 조건확인: 중간 색
- 비우선/기준미달: 흐린 색
- 아이콘 클릭 시 적용근거, 현재 제도판정, 종상향, 용적률, 공공기여 표시
- 상세 검토표로 이동 가능

지도
- 첫 화면 좌측 대형 지도
- Leaflet Draw 도구 확대
- 구역 작성 전: '사업지 범위를 그리시오'
- 구역 작성 후: '위치도 · 대상구역 설정'
- 이후 필지/건축물/역세권 레이어를 계속 표시

우측 정보
- 토지: 구역면적, 필지수, 90㎡ 미만, 공식면적 확보율, 지목 구성
- 건축물: 건축물수, 노후건축물수, 노후도, 총연면적, 주용도 구성
- 기존 상세 토지대장/건축HUB 표는 접어서 하단 상세원장으로 유지

기존 엔진
- 8개 제도 동시검토
- 용도지역 상향
- 제도상 용적률
- 공공기여/기부채납
- 지하철역사 SHP 연결 엔진
