v2.2.1 — 결과물 작성 영역 분리

UI 구조 변경
- 목적사업 / 토지확보여부 / 의뢰·추진주체 아래에 독립된 '결과물 작성' 박스 신설.
- 오른쪽 '검토가능 사업방식' 박스에는 14개 사업방식 카드와 선택근거만 남김.
- 결과물 작성 4단계:
  1. 우선순위 사업 검토
  2. 시뮬레이션
  3. 보고서 인쇄
  4. 설계의뢰

우선순위 사업 검토
- 14개 사업방식 Candidate Engine 결과에서 1·2·3순위 표시.
- 각 순위별 최종판정, 선정근거, 조건미달/추가확인, 밀도잠재력 표시.
- 우선순위 확인 후 시뮬레이션으로 바로 이동 가능.

시뮬레이션
- 기존 '우선순위 사업 시뮬레이션'을 '사업 시뮬레이션'으로 역할 분리.
- 1·2·3안의 기반시설, 용적률, 연면적, 세대수 비교 기능 유지.

보고서 인쇄
- 기존 보고서 미리보기/PDF 인쇄 유지.

설계의뢰
- 현재 검토조건, 대상지 현황, 1·2·3순위 사업방식, 의뢰 검토범위를 자동으로 묶은 '설계의뢰 초안' 생성.
- 회사계정/개인정보/정식 접수채널이 확정되기 전에는 외부 서버로 전송하지 않음.
- 의뢰초안 복사 기능만 제공.

레이아웃
- 데스크톱: 왼쪽 3개 입력박스 아래 결과물 작성 4개 버튼, 오른쪽 사업방식 패널은 2행 높이 유지.
- 중간화면: 결과물 2×2, 사업방식 패널은 아래로 이동.
- 모바일: 결과물 1열.
