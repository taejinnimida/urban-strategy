# 서울 도시검토 플랫폼 Web MVP v2.4.0

주소를 입력하거나 지도에 구역계만 그리면 토지·건축물·역세권·중심지·도시계획을 자동 분석하고, 서울의 정비·개발사업 14개를 동시에 비교하는 초기검토 플랫폼입니다.

## 사용자 흐름

1. 주소 입력 또는 구역계 작성
2. 자동분석
3. 가능한 사업방식과 탈락·확인 사유 확인
4. 필요할 때만 목적사업·토지확보·추진주체로 순위 정교화

시스템이 알 수 있는 용도지역·역거리·노후도·과소필지·도시계획시설·정비구역은 사용자에게 묻지 않습니다. 일반화면은 핵심값만, 상세화면은 원자료·도면·판정근거·용적률 단계를 보여줍니다.

## v2.4.0 핵심

- 14개 사업방식 판정행에 `자료유형 / 기준일 / 조문·장·절 / 부족값 / 다음 조치 / 대안 / 신뢰등급`을 연결했습니다.
- 자료유형은 법률·시행령, 조례, 운영기준, 지침, 기본계획으로 구분합니다.
- 최신 공식 세부기준을 확인하지 못한 값은 `PASS`가 아니라 `REVIEW`로 낮춥니다.
- 법정 최소·최대면적은 하드게이트입니다. 미충족 사업은 추천 1·2·3순위와 시뮬레이션에서 제외합니다. 명시적 예외가 있는 경우에도 승인 전까지 추천하지 않습니다.
- 기존 정비구역·정비예정구역·재정비촉진구역과 역세권활성화·성장잠재권·도심공공주택복합사업의 배타관계를 반영했습니다.
- 안심주택 주거지역은 시장 지정 세부범위 확인 전 `REVIEW`, 장기전세 간선도로 교차지는 도로경계 200m를 판정합니다.
- 결과표에 왜 탈락했는지, 기준까지 얼마가 부족한지, 무엇을 확인·변경할지, 구역조정·대체사업을 표시합니다.
- 신뢰등급은 `자동확정 / 조건부 / 공부·현장 확인`입니다.
- 용적률은 법적상한→상한→허용→기준 순의 `최대확보 시나리오`를 기본으로 하되 확정 계획용적률과 구분합니다. 숫자 아래에 근거 유형·기준일·장절을 표시합니다.
- 분석마다 분석번호를 부여하고 오류신고에 주소·PNU·면적·추천결과와 함께 자동 첨부합니다.
- `⚙ 관리자`에서 익명 이용통계, 분석 대상지, 분석번호, 오류신고와 `접수/확인 중/처리완료` 상태를 관리합니다.
- GitHub 웹 업로드로 폴더가 풀려도 실행되는 평면·폴더 겸용 배포구조로 라이브 장애를 막았습니다.

세부 판정 출처와 보수적 처리사항은 `RULE_AUDIT_v2.4.0.md`를 확인하십시오.

## 공간정보와 도면

- 토지: 선택필지, 공식면적, 지목, 국공유지, 과소필지, 실폭도로
- 건축물: 건축물 도형, 사용승인일, 노후·비노후·미확인, 노후연면적
- 역세권: 역사 경계와 250m·350m·500m 포함률
- 중심지: 서울 중심지체계 범역과 중첩
- 도시계획: 용도지역·지구, 도시계획시설, 지구단위계획구역, 정비구역·정비예정구역, 재정비촉진지구·구역

필지·과소필지, 건축물·노후도, 역세권, 중심지, 도시계획은 각각 직관적인 미니도면으로 표시합니다. 정비구역은 서울시 `UQ181` 법정자료를 우선하고 `UQ120` 사업·후보자료를 보조로 사용합니다.

- UQ181: <https://data.seoul.go.kr/dataList/OA-20957/F/1/datasetView.do>
- UQ120: <https://data.seoul.go.kr/dataList/OA-22712/F/1/datasetView.do>

공개 공간자료는 참고자료이므로 최종 판단 전에 결정고시·정비계획·지형도면을 재확인해야 합니다.

## 접도율 GIS

불가능한 기능이 아닙니다. 현재 다음 구조가 구현돼 있습니다.

- 1순위: `TL_SPRD_RW` 실폭도로 폴리곤
- 2순위: 도로중심선 + `ROAD_BT` 등 공식 폭원으로 폭원/2 버퍼
- 계산: 6m 이상 도로, 필지별 총 접도길이, 최장 연속접도 4m, 건축물 접도율
- 공식 실폭도로가 아닌 중심선 보조값은 `AUTO(예비)`이며 그 값만으로 법정요건을 PASS 처리하지 않음

공식 서울 원본을 `road_seoul.zip`으로 한 번 설치하면 일반 사용자는 구역계만으로 자동분석합니다. 제공기관 이용승인이 필요한 원본은 배포 ZIP에 재배포하지 않습니다.

- 주소정보 전자지도: <https://business.juso.go.kr/addrlink/adresInfoProvd/guidance/provdAdresInfo.do>
- VWorld 실폭도로 30057: <https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=MK&dsId=30057>

## 관리자·통계·오류신고

회원가입 없이 브라우저별 익명 ID와 분석번호를 발급합니다.

- 저장: 분석번호, 입력주소, PNU, 면적, 필지수, 중심점, 추천결과, 오류내용
- 저장하지 않음: 이름, 원문 IP, 원본 구역계
- 연락처: 사용자가 답변을 원해 직접 입력한 경우에만 저장
- `DATABASE_URL` 있음: PostgreSQL 영구저장
- `DATABASE_URL` 없음: 배포·재시작 시 사라지는 메모리 저장
- 관리자 주소: `/admin`
- 사용자명: `admin`
- 암호: Render 환경변수 `ADMIN_PASSWORD`

## GitHub 웹 업로드

배포 ZIP은 폴더 없이 다음 파일을 한 번에 올릴 수 있게 구성합니다.

```text
app.py
app.html
stations.json
centers.json
uq181_legal.zip
uq120_project.zip
requirements.txt
Dockerfile
render.yaml
.gitignore
.dockerignore
README.md
RULE_AUDIT_v2.4.0.md
CHANGELOG_v2.4.0.txt
regression_checks.py
```

기존 `data/`, `static/` 폴더구조도 그대로 지원합니다. `/health`의 `asset_layout`과 `asset_files_ready`로 배포 누락을 확인할 수 있습니다.

## 환경변수

- `BUILDING_HUB_API_KEY`
- `VWORLD_API_KEY`
- `VWORLD_DOMAIN`
- `ADMIN_PASSWORD`
- `DATABASE_URL`
- `ROAD_DATA_CRS`: 도로 ZIP에 PRJ가 없을 때만 지정. 기본 `EPSG:5174`

## 실행·검증

```bash
pip install -r requirements.txt
python regression_checks.py
uvicorn app:app --host 0.0.0.0 --port 8000
```

## 판정 원칙

- 공식자료가 없으면 숫자를 만들지 않습니다.
- 하드게이트 미달은 가능한 사업처럼 추천하지 않습니다.
- 예외·심의경로는 승인 전까지 조건부입니다.
- 법정구역과 후보자료가 중첩되면 법정구역을 우선합니다.
- GIS 자동판정도 공식 고시·조서·현장조사를 대체하지 않습니다.
- 결과는 정비구역 지정, 심의, 인허가, 사업성·조합설립 가능성을 확정하지 않습니다.
