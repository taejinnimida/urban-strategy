v2.2.4 — 서비스형 화면 재편

목표
- 전문가용 계산·디버깅 화면을 외부 사용자용 서비스 화면과 분리.
- 스크롤을 줄이고, 사용자가 직접 입력해야 하는 항목과 자동분석 결과의 위계를 재정리.
- 기존 Rule Engine/GIS/시뮬레이션 계산 로직은 유지.

1. 상단 정리
- '서울 도시정비플랫폼' 제목의 빨간색 강조 제거 → 중립적인 진회색.
- 상단의 구역면적 AUTO / 건축HUB 준비 / 필지공간 AUTO / 토지대장 준비 / 건축물 AUTO / 도시계획GIS 준비 상태문구 비표시.
- 부제는 '서울특별시 도시정비·개발 사전검토'로 단순화.

2. 1페이지 — 사업검토
좌측
- 검토대상지
- 기존 위치도/구역계 그리기/주소 입력 기능 그대로 이동

우측
- '사업지 및 사업추진 이슈'로 사용자 입력 3개를 하나로 묶음
  · 목적사업
  · 토지확보여부
  · 사업시행자 지위
- 검토가능 사업방식 14개를 바로 표시
- 결과물 작성 박스를 검토가능 사업방식 바로 아래 배치
  · 우선순위 사업 검토
  · 시뮬레이션
  · 보고서 인쇄
  · 설계의뢰

3. 검토가능 사업방식
- 카드 클릭 시 더 이상 긴 상세검토표 위치로 스크롤하지 않음.
- 개별 사업방식 상세 팝업에서 다음 내용을 표시:
  · 후보판정
  · Rule Engine 판정
  · 왜 되는지 / 왜 안 되는지 단계별 근거
  · 법정/정량 검토항목
  · 용도지역 상향, 용적률, 공공기여
  · 밀도잠재력
- '14개 전체 비교' 버튼 추가.
- 전체 비교 역시 팝업으로 표시하고, 행을 클릭하면 해당 사업방식 상세 팝업으로 이동.

4. 2페이지 — 토지·건축물·도시계획 현황
- 기존에 길게 펼쳐지던 현황자료를 6개 요약카드로 축약:
  · 토지
  · 건축물
  · 역세권
  · 중심지
  · 도시계획 GIS
  · 종합현황
- 카드 클릭 시 상세현황 팝업 열림.
- 기존 토지/건축물 미니맵, 도시계획 GIS, 필지편집, 상세원장, 재조회 기능은 삭제하지 않고 상세 팝업 내부로 이동.
- 서비스 화면에는 핵심값만 노출.

5. 화면 크기
- 1920px급 모니터에서 1페이지가 가능한 한 한 화면에 가깝게 보이도록 압축.
- 검토가능 사업방식은 넓은 화면에서 7열 × 2행.
- 1500px 이하, 1000px 이하, 모바일에서 자동 재배치.
