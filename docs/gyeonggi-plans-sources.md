# 경기도 상위 및 관련계획 — 자료 확인 기록

확인일: 2026-11-12

작업 브랜치: `urban-plans-gyeonggi`

초기 모델 기준: `urban-analysis`의 `16c95cca5dd74c459ae2d8d5b34f3b8e24f75462`

## 범위

경기도 자료 50건·공식 링크 62개를 추가한다. 도 전체 계획 6건, 31개 시·군의 기본계획 공개본 31건, 확인된 후속 수립이력 12건, 안산 공원녹지계획 1건이다. 서울 자료 24건·40개 링크는 변경하지 않는다.

목록은 공식 공개본과 확인된 절차를 기록한다. 모든 분야·지역별 특화계획·생활권계획·최신 변경고시가 완비되었다는 뜻은 아니다. 시·군 기본계획 공개본은 국토교통부 토지이음의 실제 자료실 게시물과 첨부파일 표시를 확인했고, 파주·광주는 시군의 새 승인자료로 보완했다. 김포는 공식 시청 페이지의 일부변경 자료를 함께 연결했다.

- 토지이음 게시일은 승인·수립일로 사용하지 않는다.
- 목표연도와 추진 이력 날짜를 구분한다. 승인 예정일을 승인 완료로 기록하지 않는다.
- 경기도 광주시 자료에 광주광역시 계획을 연결하지 않는다.
- 고양의 2040 계획은 공식 보도 제목에 ‘수립’이 있어도 본문은 승인 예정이므로 수립 중으로 기록한다.
- 제2차 경기도 도시철도망 계획은 공식 승인 브리핑과 자료실 공개 보고서를 함께 연결한다. 자료실 제목의 ‘(안)’ 표기는 링크 설명에 남긴다.
- 2030 경기도 주거종합계획은 당초 수립연도만 확인했다. 재검토 자료가 공개되어 있으나 재검토 확정일은 미확인으로 남긴다.
- 안산 공원녹지계획은 승인 후 열람 공고를 연결한다. 공고에 원문 도서의 온라인 제공이 없으므로 ‘계획서 원문’ 링크로 표시하지 않는다.

공식 기관 링크의 접근 가능 여부는 기관의 일시적인 응답과 공개 정책에 따라 달라질 수 있다. 보고서 원문을 저장소에 복제하거나 내용을 자동 요약하지 않으며 계획 경계·사업 적합성을 자동 판정하지 않는다.

## 동작 확인

조회 전용과 SQLite 저장 모드에서 경기도 전체 50건, 서울 24건, 전국 합계 74건을 확인한다. 수원시와 장안구·권선구 조회에는 수원 기본계획 1건과 경기도 전체 계획 6건이 함께 나오고 성남 자료는 포함되지 않는다. 경기도 전체 목록은 30건·20건으로 나뉘며 중복·누락을 검사한다.

기존 서울 자료와 이용자가 등록한 동일 제목의 수원 자료가 있는 DB에 새 자료를 추가하는 경우도 검사한다. 사용자 링크·설명·검증 상태·변경이력과 기존 서울 자료의 숨김 상태를 보존하고, 새 초기자료 ID의 외래키 오류 없이 재시작할 수 있어야 한다.
