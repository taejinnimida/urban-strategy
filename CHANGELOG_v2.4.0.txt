도시검토 플랫폼 v2.4.0 변경 로그
기준일: 2026-08-26

1. 14개 사업방식 판정근거 전수 구조화
- 법률·시행령·조례·운영기준·기본계획·지침을 구분
- 모든 판정행에 기준일, 조문·장·절, 공식 원문 링크 필드 연결
- 최신 원문 미확보 기준은 PASS 자동 금지, REVIEW 처리
- 역세권복합개발은 최신 시행본 확인 전 자동 PASS 금지

2. 하드게이트·배타관계·예외
- 면적 미달 사업은 추천 1·2·3순위와 계획규모 시뮬레이션에서 제외
- 지원자문단·위원회 예외가 명시된 경우만 조건부 REVIEW 유지
- 주택정비형/도시정비형 재개발 배타관계 유지
- 역세권활성화: 정비구역·정비예정구역 제외, 도시정비형 정비예정구역 예외 반영
- 역세권복합개발·소규모주택정비: 정비구역 SHP 중첩값을 제외판정에 연결

3. 공식 원문 재검증 오류수정
- 안심주택: 2026-08-03 현행 운영기준의 최소 1,000㎡, 자연녹지·1종일반주거 어르신 100%·5,000㎡ 특례, 용도지역 변경, 인접·도로조건 반영
- 장기전세 간선도로 교차지역: 도로경계 200m + 구역둘레 1/8 이상 20m 도로접면 유지
- 성장잠재권: 1,500㎡ 이상, 유형1 1,500~5,000㎡, 유형2 1,500~10,000㎡ 및 지원자문단 예외 반영
- 도심 공공주택 복합사업: 공공주택 업무처리지침 제3장의2·별표 1의10 기준 연결
- 도심복합개발혁신지구: 2026-07-01 시행령 기준으로 출처 갱신

4. 경쟁력 중심 결과표현
- FAIL 행에 기준까지 부족·초과한 수치 자동표시
- 각 행에 다음 확인·변경 조치 및 대안 사업방식 표시
- 자동확정 / 조건부 / 공부·현장 확인 신뢰등급 표시
- 공식조서·결정고시·무허가·소유자·동의 관련 항목은 공부·현장 확인 등급

5. 소규모주택정비
- 소규모재건축 / 소규모재개발 / 가로·자율주택정비 후보 자동분기
- 선택 유형별 면적·노후도·도로·기존 세대수·배타관계 표시
- 모아타운은 개별사업이 아닌 관리지역 대안으로 분리

6. 계획용적률
- 종전 “수기 적용용적률” 명칭을 계획용적률로 정리
- 확보 가능한 법적상한 → 상한 → 허용 → 기준 순의 최대 시나리오를 기본값으로 적용
- 상한·법적상한은 기부채납·공공주택 등 적용조건을 경고하고 임의 숫자는 생성하지 않음
- 사업별 기본계획·운영기준·조례 근거를 입력란 바로 아래 표시
- 최신 공식 시행본이 확인되지 않은 사업은 계획용적률 숫자 자동입력 금지

7. 분석번호·오류신고·관리자
- 분석 완료 건별 UUID 분석번호 발급
- 오류신고에 분석번호·주소·PNU·면적·추천결과 자동첨부
- PostgreSQL 기존 테이블에 analysis_id 자동 마이그레이션
- 관리자 분석목록과 오류신고 목록에 분석번호 표시
- 화면 상단 “⚙ 관리자” 아이콘 고정
- 오류신고 처리상태: 접수 / 확인 중 / 처리완료

8. 유지 기능
- UQ181 법정구역 우선 정비구역 서버중첩
- UQ120 사업·후보구역 및 재정비촉진구역 별도 표시
- 토지·건축물·노후도·과소필지·역세권·중심지·도시계획 도면
- 지구단위계획·도시계획시설·정비구역 도시계획현황
- 실폭도로 우선, 도로중심선+공식폭원 예비 접도율

9. 도로 GIS 운영
- data/road_seoul.zip 설치 시 TL_SPRD_RW 실폭도로 또는 TL_SPRD_MANAGE ROAD_BT 기반 자동 공간분석
- 폭 6m 이상 도로와 필지경계의 연속 접도길이 4m 이상을 필지별 산정
- 대상지 접면 도로 수·최대 폭원·8m 도로·20m 도로 접면비율을 관련 사업방식 판정값에 자동 전달
- 폭원만으로 주간선·보조간선도로 기능등급을 추정하지 않고 공식 도로관리자료 확인 전 REVIEW
- 실폭도로 원본 미설치·도로중심선 버퍼·도형 폭원추정은 법정 PASS 금지 또는 예비등급 처리
- 관리자 화면에 공식 도로 GIS 설치상태 표시
