# 서울 도시정비플랫폼 Web MVP v2.3.0

서울 대상지의 주소를 입력하거나 구역계만 그리면 토지·건축물·역세권·중심지·도시계획을 자동 분석하고 14개 정비·개발사업을 비교하는 초기검토 플랫폼입니다.

## 사용자 흐름

1. 주소 검색 또는 지도에 구역 그리기
2. 자동분석
3. 사업방식 1·2·3순위와 핵심 검토사항 확인
4. 필요할 때만 목적사업·토지확보·추진주체로 실현성 순위 보정

시스템이 공간데이터로 알 수 있는 값은 사용자에게 묻지 않습니다. 일반 화면에는 핵심 결과만 표시하고 원자료·판정근거·용적률 단계·기반시설 계산은 상세화면에서 확인합니다.

## v2.3.0 핵심 변경

- 정비구역 분석을 브라우저 전체 SHP 다운로드 방식에서 서버 공간색인 방식으로 변경했습니다.
- 서울시 공식 `UQ181` 법정구역을 `UQ120` 사업·후보자료보다 우선하고, 재정비촉진지구·구역은 별도 트랙으로 판정합니다.
- 정비구역·예정구역의 유형·구역명·대상지 중첩률을 도시계획 현황과 도면에 표시합니다.
- 지구단위계획구역·도시계획시설·용도지역·정비구역·재정비촉진구역을 도시계획 카드에서 함께 확인합니다.
- 필지·과소필지·노후도·역세권·중심지·도시계획 미니맵을 유지하고 실폭도로 도형도 토지 도면에 표시하도록 연결했습니다.
- 법정 진입경로 또는 면적 예외가 확인되지 않은 사업은 검토카드에는 남기되 1·2·3순위와 시뮬레이션에서 제외합니다.
- 역세권활성화 기준 외 면적은 지원 자문단 인정 전 `REVIEW`로 표시하되 추천 순위에는 올리지 않습니다.
- 장기전세 간선도로 교차지역의 도로경계 200m 조건을 추가했습니다.
- 안심주택 근거를 2026년 8월 3일 개정 운영기준으로 갱신했습니다.
- 계획용적률은 확보 가능한 법적상한 → 상한 → 허용 → 기준 순의 최대확보 시나리오를 기본으로 하며, 바로 아래에 조례·운영기준·기본계획 근거를 표시합니다.
- 화면 상단에 `관리자`와 `오류·개선의견`을 추가했습니다. 오류신고에는 현재 주소·PNU·면적·추천결과가 자동 첨부됩니다.
- 관리자 화면에서 익명 방문·분석 대상지·추천결과·오류신고와 처리상태를 확인합니다.

## 공간정보와 도면

- 토지: 선택필지, 공식면적, 지목, 국공유지, 과소필지, 실폭도로
- 건축물: 건축물 도형, 사용승인일, 노후·비노후·미확인, 노후연면적
- 역세권: 역사 경계 최단거리와 250m·350m·500m 포함률
- 중심지: 서울 중심지체계 범역과 해당 중심지
- 도시계획: 용도지역·지구, 도시계획시설, 지구단위계획구역, 정비구역·정비예정/사업구역, 재정비촉진지구·구역

정비구역은 서울시 공개 공간자료를 사용한 초기검토 값입니다. 최종 판단에는 결정고시·정비계획·지형도면을 다시 확인해야 합니다.

- 서울 의제처리구역 위치정보 `UQ181`: <https://data.seoul.go.kr/dataList/OA-20957/F/1/datasetView.do>
- 서울 도시계획사업 현황 `UQ120`: <https://data.seoul.go.kr/dataList/OA-22712/F/1/datasetView.do>

## 실폭도로·접도율 자동화

플랫폼은 `TL_SPRD_RW` 실폭도로와 `TL_SPRD_MANAGE` 도로구간을 이용해 다음을 계산합니다.

- 도로 폭원
- 폭 6m 이상 도로 여부
- 필지별 총 접도길이와 최장 연속접도길이
- 폭 6m 이상 도로에 4m 이상 연속 접한 건축물 비율

실폭도로 폴리곤이 있으면 이를 우선합니다. 실폭도로가 없고 도로중심선에
`ROAD_BT` 등 공식 폭원 속성이 있으면 중심선 양측을 `폭원/2`만큼 버퍼해
예비 도로면과 접도율을 계산합니다. 이 보조값은 화면에 `AUTO(예비)`로 표시하고,
그 값만으로 법정요건을 PASS 처리하지 않습니다.

공식 전자지도 원본 다운로드는 제공기관 로그인·이용신청이 필요할 수 있어 배포 ZIP에 임의 재배포하지 않습니다. 관리자가 공식 서울 원본을 `data/road_seoul.zip`으로 한 번 설치하면 이후 일반 사용자는 별도 업로드 없이 구역계만으로 자동분석합니다. 실폭도로와 공식 폭원 모두 없으면 접도율을 임의 추정해 PASS 처리하지 않습니다.

- 행정안전부 주소정보 전자지도 안내: <https://business.juso.go.kr/addrlink/adresInfoProvd/guidance/provdAdresInfo.do>
- VWorld 실폭도로 데이터셋 30057: <https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=MK&dsId=30057>

## 관리자·이용통계·오류신고

회원가입 없이 브라우저별 익명 방문자 ID와 세션 ID를 발급합니다. 자동분석 완료 시 주소·PNU·면적·필지수·추천결과를 기록해 어떤 대상지가 검토되는지 확인할 수 있습니다.

- 저장하지 않음: 이름, 원문 IP, 원본 구역계
- 오류신고 연락처: 사용자가 답변을 원해 직접 입력할 때만 저장
- `DATABASE_URL` 있음: PostgreSQL 영구저장
- `DATABASE_URL` 없음: 재시작·배포 시 삭제되는 메모리 임시저장
- 관리자 주소: `/admin`
- 관리자 사용자명: `admin`
- 관리자 암호: `ADMIN_PASSWORD`

무료 배포라도 장기 통계를 유지하려면 PostgreSQL과 `DATABASE_URL`이 필요합니다. 관리자 암호를 소스코드에 직접 쓰지 마십시오.

## 환경변수

- `BUILDING_HUB_API_KEY`: 건축물대장 API 인증키
- `VWORLD_API_KEY`: VWorld API 인증키
- `VWORLD_DOMAIN`: VWorld 인증에 등록한 서비스 도메인
- `ADMIN_PASSWORD`: `/admin` 암호
- `DATABASE_URL`: 통계·오류신고 영구저장용 PostgreSQL 접속주소
- `ROAD_DATA_CRS`: 실폭도로 ZIP에 PRJ가 없을 때만 지정하는 원본 좌표계. 기본 `EPSG:5174`

## 실행·검증

```bash
pip install -r requirements.txt
python regression_checks.py
uvicorn app:app --host 0.0.0.0 --port 8000
```

상태 확인은 `/health`를 사용합니다. Docker 방식으로 Render에 배포하며 `COPY . .`가 `static/`과 `data/`를 함께 복사합니다.

## 판정 원칙

- 토지대장 공식면적이 없으면 필지 도형면적을 초기검토에만 사용합니다.
- 법정 면적관문 미달 사업은 추천순위와 시뮬레이션에서 제외합니다.
- 공식 예외가 있는 경우 `REVIEW`로 표시하되 인정 전에는 추천하지 않습니다.
- 법정 정비구역과 사업·후보자료가 중첩되면 법정구역을 우선합니다.
- 주택정비형과 도시정비형 재개발은 확인된 구역유형에 따라 배타적으로 우선 판정합니다.
- 자동확정할 수 없는 값은 임의 숫자로 만들지 않고 미확인·공식조서 확인·심의 검토로 남깁니다.
- 이 결과는 정비구역 지정, 위원회 심의, 사업시행인가, 건축허가, 사업성 또는 조합설립 가능성을 확정하지 않습니다.
