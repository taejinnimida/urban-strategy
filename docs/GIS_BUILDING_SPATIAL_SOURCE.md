# 건축물현황 공간도형 연동(3-1 · 3-2) — 원자료 등록 기준

## 중요한 구분

- 건축HUB **표제부 5건** = 편입필지 관련 대장 응답 5건이며, 곧바로 건축물 공간도형 5개를 의미하지 않습니다.
- GIS건물통합정보 **건물 외곽선** = 공식 건물 공간도형입니다. **도형별** 주용도·구조를 사용할 수 있는 경우 3-1·3-2 면적·지도·DXF를 작성합니다.
- 토지 필지 2개를 건물 외곽선으로 사용하는 것은 금지합니다.
- 이 작업은 서울도시정비 RULE과 무관한 독립 기초현황조사 코드입니다.

## 공공 원자료

- 원천: <https://www.data.go.kr/data/15083092/fileData.do> (국토교통부 GIS건물통합정보, SHP)
- API 소개: <https://www.data.go.kr/data/15123970/openapi.do> (GIS건물통합정보 WMS/WFS)
- `A9`: 건축물 용도명, `A11`: 건축물 구조명, `A1`: GIS건물통합식별번호(예시자료의 표준 컬럼)
- 각 자료의 실제 속성명·좌표계·갱신기준일·파일구조는 다운로드한 원본 DBF/PRJ를 확인해 확정합니다.

원자료를 받았다면 `national_data/manifest.json`에 **별도 데이터셋 항목** `3-spatial`을 등록합니다. 기존 서울 운영 앱이나 서울 파일을 참조하지 않습니다.

예시 스키마(메타데이터·레이어 이름은 실제 원자료로 교체):

```json
{
  "datasets": {
    "3-spatial": {
      "provider": "국토교통부 GIS건물통합정보",
      "source_url": "https://www.data.go.kr/data/15083092/fileData.do",
      "as_of": "원본 자료 기준일",
      "file": "gis_buildings_verified.zip",
      "crs": "EPSG:5179",
      "coverage": {
        "type": "Polygon",
        "coordinates": [[[127.0,37.0],[128.0,37.0],[128.0,38.0],[127.0,38.0],[127.0,37.0]]]
      },
      "label_field": "A1",
      "fields": {
        "building_id": "A1",
        "use": "A9",
        "structure": "A11"
      }
    }
  }
}
```

위 `coverage` 좌표는 **형식 예시**일 뿐, 실제 대상지를 포함한다는 의미가 아닙니다. 반드시 공식 SHP의 원래 범위로 수정합니다. `crs`도 원본 PRJ 확인 후 기입합니다. 파일은 신청·다운로드 권한과 출처를 확인하여 별도 등록합니다.

## 동작

1. `file:3-spatial` 조회 작업이 공식 GIS 도형을 수집하고 구역계로 자릅니다.
2. `development/building/spatial.py`가 GIS 도형의 용도(A9)·구조(A11)를 기준으로 3-1/3-2의 분류, 건물 외곽선, 건축면적·분류별 구성을 작성합니다.
3. `development/cad.py`, `development/survey_sheet.py`, 화면 주제도는 같은 도형·분류를 사용합니다.
4. 기존 건축HUB 5건 표제부 집계는 `building_registry_table`에 따로 보존합니다. GIS 도형 개수와 더하거나 일치한다고 가정하지 않습니다.
5. 공식 GIS 원도형 파일이 미등록이면 건축HUB 속성 집계만 표시하고, 건물주제도/DXF는 **미확보**로 남깁니다.

## 배포 전에 남은 필수검증

- 실제 GIS건물통합정보 원자료와 **해당 지역**의 PNU 및 건물 식별번호 원문 비교
- 원본 WMS/WFS 및 SHP 수집권한, CRS, 시점 확인
- GIS건물통합정보에서 단일 건물 다중 도형, 중첩, 지하·옥탑, 경계 걸친 도형 검증
- 건축물대장 레코드와 공간도형 연결 가능성이 명확한 경우에만 건물별 대장정보와 1:1 결합
- 통계표 분모(GIS 도형 개수 vs 대장 건수), CAD 경계와 전체 대상지 교차면적 일치 여부 확인
