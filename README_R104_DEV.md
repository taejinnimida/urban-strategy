# R104 DEV — 검토모드 분리 개발본

기준본: R103-SEOUL-UQ153. 운영 배포하지 않음.

## 실행
기존 R103 실행에 필요한 Python 환경에 fastapi, uvicorn, shapely, pyproj를 설치한 뒤:

    python -m uvicorn dev_app:app --host 127.0.0.1 --port 8104

브라우저에서 http://127.0.0.1:8104 접속.
기존 운영 시작점 `app:app`은 그대로이며 새 모드가 나타나지 않는다.
운영 Render 서비스에 업로드하거나 시작 명령을 변경하지 말 것.
운영 DB·관리자 저장소와 분리된 로컬 테스트 환경변수를 사용할 것.

## 제공 기능
- 첫 화면: 서울시 정비사업 / 비시가화지역 개발 모드 선택
- 서울 모드: 기존 home() 출력과 전체 API 유지. 개발 실행 시에만 모드선택 링크 추가
- 비시가화 모드: 관할·주소·사업유형·용도지역·면적·계획내용 입력
- WGS84 GeoJSON Polygon/MultiPolygon 1개 업로드 및 서버 유효성 검증
- 타원체 면적 산출, 배경지도 없는 구역계 미리보기
- 검토자료 현황 생성. 법정 적격 판정이 아닌 NOT_ASSESSED / UNKNOWN
- JSON 초안 내려받기·불러오기, 현재 화면 인쇄/PDF

## 아직 제공하지 않는 기능
전국 지적·용도지역·농지·산지·규제자료 자동조회, 주소검색, 지도 드로잉,
지자체별 조례 검증 및 사업 적격·제영향평가 판정, 기반시설 수요·부담금 계산.
초안은 자동 서버 저장되지 않는다. 이동·새로고침 전 초안 파일 저장 필요.
GeoJSON에 CRS를 추정 적용하지 않는다. EPSG:4326 변환을 사용자가 확인해야 한다.
면적은 법적 지적면적과 같다고 간주하지 않는다.

## 변경파일

test_development.py, 이 안내문.
기존 app.py / app.html 및 사업판정 모듈·공간데이터는 R103과 바이트 동일.
다른 사이트의 JavaScript를 복사하거나 번들에 포함하지 않음.
