## 등록 원칙

1. 제주특별자치도는 **제주시·서귀포시를 행정시로 설치**한다. 도 전체 계획은 `region=50`으로 공유 조회하고, 서귀포 천지동 활성화계획 등 한 행정시에 한정된 계획만 하위 코드에 등록한다.
2. 국제자유도시 **종합계획과 JDC 시행계획**은 별도의 레코드로 관리한다. 2026년 수립 추진 중인 수정계획을 확정계획으로 표시하지 않는다.
3. 주민공청회·의회 의견청취·용역보고·자료실 등록일을 법정 승인·고시일로 대체하지 않는다. 특히 2030 정비기본계획, 공업지역기본계획, 2040 공원녹지기본계획의 **최신 확정고시 확인이 추가로 필요**하다.
4. 등록계획의 행정구역 상속 조회는 **토지별 법정 적용 여부를 판정하지 않는다**. 결정도면·지형도면 및 실제 계획 적용범위를 별도로 확인해야 한다.

## 누락관리

관광지·관광단지 조성계획, 산업단지 관리기본계획, 제주별 도시재생활성화계획, 농촌공간 재구조화·재생 기본계획, 연안·하천·교통·도로계획은 추가 조사 대상이다. 제주특별법에 따른 개별 개발사업계획과 농지·산림·환경 분야의 관련계획도 확인할 필요가 있다.

이번 변경은 `urban-plans` 브랜치의 관련계획 데이터·테스트·문서에만 반영한다. `urban-analysis`, `main`, Render 운영 배포는 수정하지 않는다.

**검증:** JSON 등록값·중복 및 형식 점검과 GitHub 커밋은 완료했다. Python/FastAPI/SQLite 통합 테스트 실제 실행은 별도 확인이 필요하다.
