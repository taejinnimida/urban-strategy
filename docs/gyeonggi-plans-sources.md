# 경기도 상위 및 관련계획 — 자료 확인 기록

확인일: 최초 50건 2026-11-12 / 분야별 추가 20건 2026-11-13

작업 브랜치: `urban-plans-gyeonggi`

## 범위

경기도 자료 70건·공식 링크 98개를 추가한다. 도 전체 계획 6건, 31개 시·군의 기본계획 공개본 31건, 확인된 후속 수립이력 12건, 분야별 계획 21건이다. 서울 자료 24건·40개 링크는 변경하지 않는다.

목록은 공식 공개본과 확인된 절차를 기록한다. 모든 분야·지역별 특화계획·생활권계획·최신 변경고시가 완비되었다는 뜻은 아니다. 시·군 기본계획 공개본은 국토교통부 토지이음의 실제 자료실 게시물과 첨부파일 표시를 확인했고, 파주·광주는 시군의 새 승인자료로 보완했다. 김포는 공식 시청 페이지의 일부변경 자료를 함께 연결했다.

- 토지이음 게시일은 승인·수립일로 사용하지 않는다.
- 목표연도와 추진 이력 날짜를 구분한다. 승인 예정일을 승인 완료로 기록하지 않는다.
- 경기도 광주시 자료에 광주광역시 계획을 연결하지 않는다.
- 고양의 2040 계획은 공식 보도 제목에 ‘수립’이 있어도 본문은 승인 예정이므로 수립 중으로 기록한다.
- 제2차 경기도 도시철도망 계획은 공식 승인 브리핑과 자료실 공개 보고서를 함께 연결한다. 자료실 제목의 ‘(안)’ 표기는 링크 설명에 남긴다.
- 2030 경기도 주거종합계획은 당초 수립연도만 확인했다. 재검토 자료가 공개되어 있으나 재검토 확정일은 미확인으로 남긴다.
- 안산 공원녹지계획은 승인 후 열람 공고를 연결한다. 공고에 원문 도서의 온라인 제공이 없으므로 ‘계획서 원문’ 링크로 표시하지 않는다.

분야별 보강에서는 다음을 구분한다.

- 정비기본계획 5건과 분당·평촌·중동·일산·산본 노후계획도시정비기본계획 5건을 별도 등록한다. 신도시의 실제 계획경계는 원문 도면을 확인하고, 일반구 코드는 목록 탐색에만 사용한다.
- 성남 원도심 정비계획의 2026-01-06 표시는 개정 안내 보도일이다. 2024년 변경자료를 최근 개정 전체를 포함하는 통합본으로 표시하지 않는다.
- 분당 계획은 2026-11-06 경미한 변경 고시를 연결한다. 평촌 보고서의 게시일, 중동 계획의 시보 발행일은 각각 그 날짜 종류를 명시한다.
- 안양 정비기본계획은 2025-05-30 변경 보고서와 2025-06-02 면적 정정 고시를 함께 제공한다.
- 고양 일산 계획의 공개 파일명에 남은 ‘(안)’ 표기는 링크 메모로 보존하고, 수립 고시 사실은 시의 공식 보도로 교차 확인한다.
- 산본은 공식 수립 고시 보도를 연결했으며 계획서 원문 링크를 확보한 것으로 표시하지 않는다.
- 용인 공원녹지계획의 2022년 공개본과 2025년 재정비 진행 자료를 구분한다. 후속 재정비 승인 여부는 미확인이다.
- 파주 공원녹지계획과 수원 2036 도시재생전략계획은 확인된 공람·공청회 단계로 등록한다. 후속 확정 여부를 추정하지 않는다.
- 수원 기존 도시재생전략계획 변경 공개본은 목표연도·확정일을 비워 둔다. 안산 공업지역계획과 함께 보고서 공개 사실만 확인했으므로 수립상태는 미확인으로 둔다. 경관계획의 웹페이지 수정일이나 PDF 업로드 경로 역시 수립일로 사용하지 않는다.
- 안양 도시재생전략계획 재정비는 공고문에서 목표연도 2032년을 확인했다. 목록의 공고번호 제2024-63호와 검색된 첨부문서의 제2024-65호 표기 차이를 임의로 통일하지 않는다. 온라인 통합 보고서는 미확인이다.

공식 기관 링크의 접근 가능 여부는 기관의 일시적인 응답과 공개 정책에 따라 달라질 수 있다. 보고서 원문을 저장소에 복제하거나 내용을 자동 요약하지 않으며 계획 경계·사업 적합성을 자동 판정하지 않는다.

## 동작 확인

조회 전용과 SQLite 저장 모드에서 경기도 전체 70건·98개 링크, 서울 24건·40개 링크, 전국 합계 94건·138개 링크를 확인한다. 경기도 전체 목록은 30건·30건·10건으로 나뉘며 중복·누락을 검사한다. 수원시와 장안구·권선구 조회에는 수원 자료 6건과 경기도 전체 계획 6건이 함께 나오고 성남 자료는 포함되지 않는다.

기존 서울 자료와 이용자가 등록한 동일 제목의 수원 자료가 있는 DB에 새 자료를 추가하는 경우도 검사한다. 사용자 링크·설명·검증 상태·변경이력과 기존 서울 자료의 숨김 상태를 보존하고, 새 초기자료 ID의 외래키 오류 없이 재시작할 수 있어야 한다.

신도시 대상 일반구와 같은 시의 다른 일반구를 각각 조회하여 노출 범위를 검사한다. 지도 집계는 해당 지역·하위지역 등록 수이며, 조회 목록에는 상위지역 자료가 추가되는 기존 동작을 유지한다. 부문계획 필터, 공람·공청회 상태, 미확인 목표연도·날짜, 원문 없는 참고자료 구분도 확인한다. 전체 관련 검사 55개를 실행한다.

본문·고시 링크의 존재와 공개 자료를 확인했지만, 모든 링크의 현재 HTTP 응답 성공을 보장하는 검사는 아니다. 일부 기관은 직접 접속 시 일시적인 차단·시간 초과를 반환했다. PostgreSQL 운영 DB와 브라우저 렌더링 재검사는 미실행이며, Render 연결 설정과 운영 배포는 변경하지 않는다.
