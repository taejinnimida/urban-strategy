도시검토 플랫폼 v2.3.0 변경 로그
기준일: 2026-08-26

1. 정비구역 GIS 오류 보완
- 브라우저가 서울 전역 3,246개 도형을 내려받아 Turf로 교차하던 방식을 폐기.
- POST /api/spatial/renewal-intersections 서버 공간색인 방식으로 변경.
- UQ181 법정구역 우선, UQ120 사업·후보자료 보조 적용.
- 재정비촉진지구·구역은 정비사업 유형과 분리된 별도 판정 트랙 적용.
- 구역명, 유형, 대상지 중첩면적·중첩률 반환 및 도시계획 미니맵 표시.

2. 토지·건축물·도시계획 현황 및 도면
- 도시계획 현황에 용도지역·지구, 도시계획시설, 지구단위계획구역,
  정비구역·정비예정/사업구역, 재정비촉진지구·구역을 함께 표시.
- 필지·과소필지, 건축물·노후도, 역세권, 중심지, 도시계획 미니맵 유지.
- 실폭도로가 연결되면 토지 미니맵에도 도로 폭원 도형 표시.

3. 사업방식 추천 하드게이트
- 면적 예외가 미확인인 사업과 법정 진입경로 미확인 사업은 상세 검토카드에만 유지.
- 위 사업은 1·2·3순위 및 계획규모 시뮬레이션에서 제외.
- 도시정비형 비지정 대상지는 현재 연결된 의제경로의 최저 1,500㎡ 면적관문 추가.
- 사용자 의도·추진주체 미입력이 공간상 법정 진입조건 판정을 가리지 않도록 구조 수정.
- 역세권활성화 1,500㎡ 미만은 지원 자문단 인정 가능성을 REVIEW로 표시하되
  인정 전 추천순위에서는 제외.

4. 판정기준·용적률 근거
- 장기전세 간선도로 교차지역에 도로경계 200m 조건 추가.
- 안심주택 근거를 2026.08.03. 개정 운영기준으로 갱신.
- 장기전세 조례 2026.05.18. 및 운영기준 2026.03.06.을 구분 표시.
- 계획용적률은 법적상한→상한→허용→기준의 최대확보 시나리오를 기본값으로 유지.
- 계획용적률 하단에 조례·운영기준·기본계획의 적용 장·절·체계와 링크 표시.
- 근거에서 숫자를 확정하지 못하면 임의값을 생성하지 않도록 문구 보강.

5. 실폭도로·접도율 자동화 기반
- POST /api/spatial/roads 추가.
- 공식 서울 실폭도로 ZIP을 data/road_seoul.zip으로 설치하면 서버가 공간색인하고
  대상지 60m 범위만 브라우저에 반환.
- TL_SPRD_RW·TL_SPRD_MANAGE 기반 폭원, 6m 도로, 필지별 총 접도길이,
  최장 연속 4m 접도 및 건축물 접도율 계산.
- 실폭도로 폴리곤이 없을 때 도로중심선의 ROAD_BT 등 공식 폭원으로
  폭원/2 버퍼를 생성해 접도율을 예비산정하는 보조 경로 추가.
- 중심선+폭원 버퍼 또는 도형 폭 추정값은 AUTO(예비)·REVIEW로 표시하고,
  해당 값만으로 법정요건을 PASS 처리하지 않음.
- 공식 원본 미설치 시 임의 PASS 금지.
- 제공기관 로그인·이용신청이 필요한 원본은 배포 ZIP에 임의 재배포하지 않음.

6. 관리자·익명 통계·오류신고
- 화면 상단에 관리자 버튼 추가.
- /admin에서 익명 방문자, 분석 실행, 대상지 주소·PNU·면적·추천결과 확인.
- 오류·개선의견 모달 추가. 현재 대상지와 추천결과 자동 첨부.
- 관리자 화면에서 오류 유형·내용·연락처·처리상태 접수/확인 중/완료 관리.
- DATABASE_URL 설정 시 PostgreSQL 영구저장, 미설정 시 메모리 임시저장.

7. 검증
- regression_checks.py 추가.
- 서버 정비구역 법정자료 우선, 비중첩, 1,399㎡ 재개발 면적 FAIL,
  오류신고 저장, 관리자·오류신고·도로 UI 연결을 회귀검사.
- Python 컴파일, 프론트엔드 JavaScript 구문, uvicorn 주요 엔드포인트 확인.

8. 배포 시 추가 환경설정
- ADMIN_PASSWORD: 관리자 Basic 인증 암호.
- DATABASE_URL: 통계·오류신고 영구저장.
- road_seoul.zip: 선택. 공식 원본 설치 시 접도율 자동 활성화.
