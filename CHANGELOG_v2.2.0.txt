v2.2.0 — 사업방식 11개 → 14개 확장

추가 1. 일반 주택건설사업
- 특례사업 비교의 Baseline.
- 목적사업: 주거 우선, 주거복합은 대안.
- 토지권원·사업주체 구조를 먼저 확인.
- 공동주택 30세대 이상은 주택법 사업계획승인 경로 표시.
- 30세대 미만은 개발불가로 처리하지 않고 건축허가 등 별도 인허가 경로로 표시.
- 종상향 특례 없이 현행 용도지역 서울시 조례용적률을 계획규모 기준값으로 사용.
- 특례 공공기여 없음. 법정 기반시설·공원·주택건설기준은 별도.

추가 2. 성장잠재권 활성화사업
- 서울시 운영기준 2026.05.28 기반.
- 비역세권 면적 50% 이상 원칙.
- 용도지역: 2종일반(7층 포함)·3종일반·준주거.
- 도로: 35m 이상 간선도로 + 전체 둘레 1/8 이상 접면 + 2면 이상 6m 도로.
- 35m 간선도로는 서울시 도로관리시스템 기준 최종확인이 필요.
- 현재 플랫폼이 해당 원본을 직접 확보하지 못했으므로 '도시계획도로 후보'만으로 PASS 금지.
- 도로관리시스템 확인을 사용자가 입력해야 PASS 가능.
- 35m에서 5m 이내 차이는 지원자문단 예외 인정 입력 시 반영.
- 유형1 지구단위계획: 1,500~5,000㎡.
- 유형2 도시정비형 재개발: 1,500~10,000㎡.
- 기준 외 면적은 지원자문단 예외 인정 확인 시 반영.
- 노후도는 사업유형별 기준이 달라 별도 충족확인 입력을 요구. 자동 노후도만으로 PASS 강행하지 않음.
- 용도지역 변경 최대 2단계 원칙, 위원회 인정 시 3단계.
- 공공기여: 증가용적률 50% 부지면적 환산 기준표 연결.

추가 3. 상생주택
- 서울시 민간토지 활용 공공주택 건립 운영기준 기반.
- 저이용·유휴토지등 또는 민간 제안 토지 여부 하드검토.
- 규모: 3,000㎡ 이상 OR 공동주택 100세대 이상.
- 도시자연공원구역·비오톱1등급·GB·공익용산지 등 정책상 제외여부 별도 입력.
- 추진방식:
  · 민간토지사용형
  · 공동출자형
  · 민간공공협력형
  · 민간토지매입형
- 민간 제안은 가능하지만 실제 사업화에는 서울시·SH·공공법인 등 공공 참여가 필요하므로 민간 단독 추진주체 입력 시 REVIEW.
- 운영기준 용도지역·용적률·공공기여율 표 연결.
- 용도지역 변경 공공기여는 증가용적률 60%, 세분변경은 50% 환산 구조 표시.
- 도시계획시설 해제·기타 규제완화 공공기여는 별도 중첩 가능.

Candidate Engine
- 14개 모두 기존 순차 하드게이트 유지:
  목적사업 → 토지확보·추진주체 → 법정진입 → 입지·정량 → 의제·실행경로
- 신규 사업도 density가 hard gate를 뒤집지 못함.
- 성장잠재권은 35m 도로 미확인 상태에서 밀도잠재력이 높아도 PASS 불가.

- 선택필지 공식면적 합계, 현황기반시설, 국공유지, 기초 순수대지 구조 유지.
