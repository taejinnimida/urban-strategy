도시검토 플랫폼 v2.5.0 r23 — 공익용산지 원도형 연결
기준일: 2026-09-02

1. 내장 공간자료
- 국토교통부 연속주제도 산지구분도 UF801 서울 2026-08 원본 추가
- 배포파일: forest_classification_seoul_202608.zip
- 원좌표계: EPSG:5174

2. 분류 원칙
- MNUM UFM120: 공익용산지
- MNUM UFM110: 임업용산지
- MNUM UFM200: 준보전산지
- MNUM UFM100: 보전산지 상위분류
- ALIAS가 빈 레코드도 있으므로 MNUM 코드를 우선 사용
- UFM100 상위분류는 공익용산지 면적에 합산하지 않음

3. 분석 변경
- 공익용산지를 필지별 VWorld NED 조회가 아닌 UF801 원도형과 구역계의 실제 공간교차로 우선 판정
- 실제 중첩도형, 중첩면적(㎡), 대상지 대비 비율(%) 반환
- 임업용산지도 별도 색인·교차하여 공익용산지와 혼합되지 않도록 분리
- 원도형 로드 실패 시에만 기존 NED 필지조회 사용

4. 화면 변경
- 공익용산지 도면을 해당 필지경계가 아닌 실제 교차도형으로 표시
- 공간현황·사업검사서·진행상태에 공익용산지 중첩면적과 비율 표시
- 자료출처와 UFM120 분류기준 명시

5. 진단 API
- GET /api/spatial/forest-classification-data-status
- POST /api/spatial/forest-classification-intersections

앱 본체 버전은 사용자 지시에 따라 v2.5.0을 유지함.
