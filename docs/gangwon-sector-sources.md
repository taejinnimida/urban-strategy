# 강원특별자치도 분야별 법정계획 1차 보강 기록

**확인 기준일:** 2026-11-13  
**개발 브랜치:** `urban-plans`  
**자료 파일:** `plan_catalog_assets/gangwon-sector-additions.json`

## 수집 결과

강원 1차 기본 구축 26건 외에 분야별 **20개 계획 / 27개 기관자료 링크**를 추가했다. 원주·춘천·강릉·속초·태백 5개 시의 공식 공개 자료를 대상으로 하며, 나머지 13개 시·군의 분야별 계획이 없다는 뜻은 아니다.

## 정확성 기준

1. **공고·고시·의회 의견청취·용역발주·전략환경영향평가 공개**를 서로 구분한다. 계획 수립 중을 완료로 변경하지 않는다.
2. 시청 공개본이 있다고 해서 최신 법정 유효본임을 보증하지 않는다. 개별 지역의 최종 결정·변경 고시와 지형도면 확인이 필요하다.
3. 도시재생전략계획과 개별 도시재생활성화계획은 분리해 등록한다. 동일한 원문에 여러 이력이 있을 경우 그 의미를 note에 적는다.
4. 현재 플랫폼은 **계획명·원문 찾아보기** 기능으로, 관련계획에 따른 대상지의 사업 가능 여부를 판정하지 않는다.
5. 강릉 도시관리계획 재정비, 춘천 도시관리계획 재정비안은 도시계획정보의 보완자료이며, 이를 이용해 자동 RULE을 실행하지 않는다.
