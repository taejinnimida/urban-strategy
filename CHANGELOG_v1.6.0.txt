v1.6.0 — VWorld 도시계획 GIS 연결

자동조회
- 용도지역: LT_C_UQ111
- 용도지구/구역: LT_C_UQ121, 123, 124, 125, 126, 128, 129, 130, 162, LT_C_UD801
- 도시계획시설: LT_C_UPISUQ151~159
- 지구단위계획: LT_C_UPISUQ161
- 개발행위허가 제한: LT_C_UPISUQ171

분석
- 대상구역 polygon과 각 도시계획 polygon 실제 교차
- 용도지역별 대상지 중첩면적/비율
- 최대면적 용도지역 자동 추출
- 복수 용도지역 혼재 여부 표시
- 용도지구/구역 중첩 현황
- 도시계획시설 유형별 건수 및 중첩면적
- 지구단위계획 중첩면적/비율
- 개발행위허가 제한 중첩 여부

8개 사업방식 연동
- 도시계획 GIS가 정상 조회되면 최대면적 용도지역을 현재 용도지역 1차값으로 자동 사용
- 복수 용도지역이면 화면에 혼재 경고
- GIS 미응답 시 기존 수기 용도지역 입력값 사용

UI
- 대상지 현황에 '도시계획 GIS' 블록 추가
- 용도지역 구성 / 용도지구·구역 / 도시계획시설 / 지구단위계획 요약
- 별도 작은 도시계획 도면 표시
- 메인 위치도는 계속 사업구역 경계만 표시
