v1.9.1 — 구역계 입력 UX + 공간도면 시각위계 보완

1. 구역계 입력 방식
- 기존 Leaflet 아이콘형 그리기 도구를 화면에서 제거
- '지도에 그리기' / '주소로 입력하기' 두 방식으로 분리
- 사각형 그리기 기능 제거, Polygon 구역계만 사용
- 지도 그리기 방법 2단계 설명 추가

2. 주소로 입력하기
- 서울특별시 지번주소 전용
- 입력형식: 구, 동, 지번
- 한 줄에 한 필지, 여러 줄 동시 입력
- 예: 동대문구, 장안동, 123-4
- VWorld 주소검색 → PNU 우선 또는 검색좌표-연속지적 공간매칭
- 확인된 모든 필지를 지도에 파란색 Preview로 동시 표시
- '표시 필지로 구역계 설정' 시 필지 도형을 합쳐 구역계 생성 후 전체 자동분석 실행
- 미확인 주소는 상태창에 별도 표시

3. 토지 도면
- 구역계: 가장 굵은 선
- 구역 내 필지: 진한 선 + 약한 면채움
- 90㎡ 미만 내부필지: 별도 강조
- 구역 밖 45m 주변 지적: 매우 얇은 회색선, 면채움 없음
- 지도 범위는 대상지를 기준으로 유지하여 주변 지적이 화면을 지배하지 않도록 함

4. 건축물 도면
- 구역 내 건축물: 진한 선과 기존 노후도 색상
- 구역 밖 45m 주변 건축물: 얇은 회색선
- 노후건축물은 내부에서만 강하게 강조

5. 역세권 도면
- 역사 및 250m/350m 전체 범위: 맥락선으로 옅게 표시
- 대상지와 250m/350m가 실제 중첩되는 부분: 면으로 진하게 표시
- 대상지 구역계: 가장 굵게
- 화면범위는 대상지+최근접 역사 중심

6. 중심지 도면
- 중심지 전체 폴리곤: 옅은 배경/얇은 선
- 대상지와 중심지가 실제 중첩되는 부분: 진한 면
- 대상지 구역계: 가장 굵게
- 화면범위는 대상지 중심으로 유지

7. 기존 기능
- 서울 도시정비플랫폼 명칭, 9개 사업방식, 지하철역사/중심지 서버내장, 도시계획 GIS, 모바일 반응형 유지
