도시검토 플랫폼 v2.5.0 r24 — 사업판정 후보색·밀도 UI 개편

기준본
- v2.5.0 r23 공익용산지 원도형 연결본
- 앱 표시 버전은 v2.5.0 유지

사업카드 의미
- 파란색: 현재 조건으로 추진 가능
- 빨간색: 조건변경 후 추진 가능
- 회색 실선: 조건조정만으로 추진경로를 만들기 어려움
- 회색 점선: 자료·공식기준 추가확인 또는 자동판정 대기

빨간색 산정
- 면적 부족: 부족면적과 인접필지 편입 표시
- 면적 상한 초과: 초과면적과 구역계 축소 표시
- 시행구조 불일치: 사업시행자·토지확보 구조 변경 표시
- 노후도 부족: 1년 뒤 기준일 재산정 또는 기준 10%p 이내일 때 인접 노후건축물 편입 검토 표시
- 개발제한·공익용산지·비오톱·문화재·군사·보전지역 등 하드 제한은 빨간색에서 제외

색상 명도와 순위
- 파랑과 빨강 모두 계획가능용적률 4단계로 명도 구분
- 600% 이상 / 400~599% / 250~399% / 250% 미만
- 공공기여와 역세권 가중치는 색상 명도 산정에서 제외
- 현재 가능 사업을 우선하고, 같은 추진가능성 그룹에서는 계획가능용적률을 최우선 비교
