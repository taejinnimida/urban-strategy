v1.4.0 — 승강장 경계 GIS 자동분석

공식 공간자료
- 행정안전부 주소기반산업지원서비스
- 주소정보제공 → 제공하는 주소 → 기타자료 → 기타자료활용
- TL_SPSB_STATN(지하철역사) SHP

동작
1. 주소기반 기타자료 서울 ZIP을 '지하철역사 ZIP 연결'에 1회 선택
2. TL_SPSB_STATN 레이어만 자동 추출
3. GeoJSON으로 변환 후 브라우저 IndexedDB에 저장
4. 이후 새로고침/재접속 시 저장자료 자동 복원
5. 대상구역을 그리면 자동으로:
   - 가장 가까운 지하철역사명
   - 대상구역 ↔ 역사 경계 최단거리
   - 250m 역세권 포함면적률
   - 350m 역세권 포함면적률
   - 500m 역세권 포함면적률
   계산
6. 지도에 가장 가까운 역사 경계와 250/350/500m buffer 표시
7. 수기 '승강장 경계 최단거리' 입력값을 AUTO 값으로 대체

8개 제도 반영
- 주택재개발/재건축: 250m 원칙, 250~350m 심의검토
- 역세권활성화: 250/350m 거리 자동
- 안심주택: 250/350m + 대상지 포함률 자동
- 역세권복합개발: 250m 자동
- 역세권 장기전세: 350/500m + 500m 전체 포함률 자동
- 도심공공주택복합: 500m + 과반 포함률 자동
- 도심복합혁신지구: 350/500m + 해당 범위 포함률 자동

주의
- 환승역 노선수, 중심지체계는 TL_SPSB_STATN만으로 확정하지 않고 기존 입력값 유지.
- 원본 주소기반 데이터의 누락/경계오류 가능성은 공식자료 갱신 시 함께 반영.
