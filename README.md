# 도시검토 플랫폼 Web MVP v2.3.0

서울시 대상지의 구역계만 입력하면 토지·건축물·도시계획 공간정보를 불러오고, 적용 가능한 정비·개발사업을 비교하는 초기검토 플랫폼입니다.

## 사용자 흐름

1. 주소를 검색하거나 지도에 구역을 그립니다.
2. 필지·건축물·역세권·중심지·도시계획 정보를 자동 분석합니다.
3. 14개 사업방식의 후보와 판정근거를 확인합니다.
4. 필요한 경우 목적사업·토지확보·추진주체를 선택해 실현성 순위를 보정합니다.

시스템이 공간데이터로 확인할 수 있는 값은 사용자에게 다시 묻지 않습니다. 목적사업, 토지확보 상태, 추진주체처럼 데이터로 알 수 없는 의도와 사정만 선택 입력으로 받습니다.

## 주요 기능

- 웹 지도 Polygon·Rectangle 작성 및 주소 검색
- 구역 내 필지 확정과 공식 대지면적 조회
- 지목·국공유지·도시계획시설 중첩 및 기초 순수대지 산정
- 건축물대장 기반 건축물 수·노후도·노후연면적 분석
- 90㎡ 미만 과소필지와 6m 도로 접도 검토
- 역사 경계 기준 250m·350m·500m 역세권 분석
- 서울시 중심지 체계와 대상지 중첩 검토
- 용도지역·용도지구·도시계획시설·지구단위계획 현황
- 정비구역·정비예정구역·정비가능구역과 재정비촉진지구·구역 판정 구조
- 14개 정비·개발사업 PASS·REVIEW·FAIL 비교
- 일반 사용자용 요약화면과 전문가용 판정근거·원자료 분리

## v2.3.0 변경사항

- 목적사업·토지확보·추진주체를 필수입력에서 선택 보정값으로 변경했습니다.
- 구역계가 입력되면 사용자 의도 입력 없이 공간조건 기준 1차 검토를 시작합니다.
- 필지·과소필지·노후도·역세권·중심지·도시계획 미니맵을 현황 페이지에 복원했습니다.
- 도시계획 현황에 지구단위계획구역, 정비구역·정비예정구역, 정비가능구역, 재정비촉진지구·구역을 추가했습니다.
- 주택정비형과 도시정비형 재개발의 배타관계를 반영했습니다.
- 주택정비형 재개발 대상지가 역세권 250m 이내이면 준주거지역 종상향 가능성 검토, 250~350m이면 위원회 심의에 따른 범위 확대 가능성 검토를 표시합니다.
- 역세권활성화 면적 원칙 미충족을 즉시 제외하지 않고 지원 자문단 인정 가능성을 REVIEW로 표시합니다.
- 5,000㎡ 이상 대상지는 사전협상 대상지 요건을 우선 확인하고, 사업범위 조정 또는 단계별 추진 검토 코멘트를 표시합니다.

## 공간정보 해석

공개 GIS 중첩은 초기검토용 참고값입니다. 정비구역·정비예정구역·지구단위계획구역·도시계획시설은 결정고시, 지형도면, 정비계획 및 자치구 소관부서에서 다시 확인해야 합니다.

현재 정비구역·정비예정구역 도형 원본은 배포파일에 포함되지 않았습니다. v2.3.0은 구역 유형별 판정 우선순위와 수기검증 구조를 먼저 연결했으며, SHP 또는 API가 추가되면 GIS 중첩값이 수기값보다 우선하도록 확장할 수 있습니다.

## 구성 파일

GitHub 저장소 루트에 다음 파일을 둡니다.

- `app.py`
- `requirements.txt`
- `Dockerfile`
- `render.yaml`
- `.gitignore`
- `README.md`

## 환경변수

- `BUILDING_HUB_API_KEY`: 건축물대장 API 인증키
- `VWORLD_API_KEY`: VWorld API 인증키
- `VWORLD_DOMAIN`: VWorld 인증에 등록한 서비스 도메인

API 키는 GitHub 파일에 직접 작성하지 않습니다.

## 로컬 실행

```bash
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

브라우저에서 `http://localhost:8000`을 열고, 상태는 `http://localhost:8000/health`에서 확인합니다.

## Render 배포

Docker 방식으로 배포합니다. `render.yaml`은 `/health`를 상태확인 경로로 사용합니다. GitHub에 변경 파일을 올리면 Auto Deploy가 활성화된 경우 새 배포가 시작됩니다.

## 검증 원칙

- 토지대장 공식면적 `lndpclAr`의 null·공란·0은 공식면적으로 인정하지 않습니다.
- 공식면적이 없으면 필지경계 도형면적을 초기 스크리닝에만 사용합니다.
- 도형면적 160.99㎡는 90㎡ 미만 과소필지로 분류하지 않습니다.
- 도형면적 58.05㎡는 90㎡ 미만 과소필지로 분류합니다.
- 건축물 현황은 전체·노후·비노후·미확인·노후도·노후연면적비율을 구분합니다.
- 건축물대장의 대지면적은 필지 공식면적을 대체하지 않고 교차확인용으로만 표시합니다.
- 자동판정이 불가능한 값은 임의 숫자로 만들지 않고 미확인·공식조서 확인·심의 검토로 남깁니다.

## 한계

이 플랫폼은 사업방식의 초기 선별과 검토전략 수립을 지원하는 MVP입니다. 정비구역 지정, 위원회 심의, 사업시행인가, 건축허가, 사업성 또는 조합설립 가능성을 확정하지 않습니다.
