v2.2.8 — 익명 이용통계·관리자 메뉴

1. 익명 방문자 식별
- 회원가입 없이 브라우저 localStorage에 무작위 visitor_id 발급.
- 탭·브라우저 세션별 session_id 발급.
- 이름, 이메일, 원문 IP 미수집.

2. 실제 분석 실행 기록
- 단순 페이지 방문과 자동분석 완료를 분리.
- 주소, 선택 PNU, 구역면적, 필지수, 중심점, 1·2·3순위, 제외·REVIEW 건수 기록.
- 같은 대상지·같은 결과의 반복 렌더링은 세션 내 중복 기록하지 않음.
- 원본 구역계 GeoJSON은 저장하지 않음.

3. 관리자 메뉴
- `/admin` HTTP Basic 인증. 사용자명 admin, 암호 ADMIN_PASSWORD 환경변수.
- 전체 익명 방문자, 분석 실행 방문자, 총 분석, 오늘 분석 표시.
- 최근 300건의 대상지 주소, 면적, 필지수, 추천결과, PNU, 지도 링크 표시.
- '이 브라우저 통계 제외/다시 포함' 기능.

4. 저장소
- DATABASE_URL 설정 시 PostgreSQL 테이블·인덱스 자동생성 및 영구저장.
- DATABASE_URL 미설정 시 최대 5,000건 메모리 임시저장.
- 관리자 화면에 PostgreSQL 영구저장/메모리 임시저장 상태 표시.

5. 이용자 고지
- 서비스 하단에 익명 식별자·분석기록·대상지 수집항목 표시.
- 이름·이메일·원문 IP·원본 Polygon 미저장을 명시.
