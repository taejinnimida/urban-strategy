# 충청북도 상위 및 관련계획 수집 기록

- 수집 기준일: 2026-11-13
- 파일: `plan_catalog_assets/chungbuk-plans.json`
- 구분: 공식기관의 원문 또는 공개된 행정절차 자료. 전체 계획과 모든 최신 변경 고시를 완비한 것은 아님.
- 신규 등록: **26개 계획, 34개 공식기관 링크**
- 주민공청회·열람 중인 계획을 확정·승인 계획으로 바꾸지 않는다.
- 기존 서울·경기·수도권 자료의 사업 RULE, 지도, 정비판정은 수정하지 않는다.

## 자료 정확성 원칙

1. 도시·군기본계획은 국토교통부 **토지이음 도시·군기본계획 자료실**의 공개본을 우선 사용했다. 페이지의 `등록일`은 계획의 승인일이 아니다.
2. 2030 진천·음성·증평 등 오래된 공개본은 당시 공개자료일 뿐 2026년 기준 최신 유효 확정본이라고 보증하지 않는다. 2040 후속 수립 여부를 반드시 별도 확인한다.
3. 제2차 충북 경관계획은 2026-05-29 공식 보도자료의 주민공청회를 수립상태로 기록했다. `2026-828` 공고문의 공청회 날짜와 행사 보도일은 일치하지 않아 **실제 개최 확인 사실**과 **공고문 기재일**을 구분한다.
4. 2027~2036 충청북도 지역개발계획은 2026-06-12 주민열람과 2026-06-29 최종보고회까지 확인된다. 실제 최종 승인·고시 확인 전에는 `hearing`으로 남긴다.
5. 청주시 공업지역기본계획은 산업단지 외 공업지역 등을 대상으로 하므로 일반 용도지역 전체에 적용한다고 해석하지 않는다.
6. 시청·도청 자료실의 **계획서 원문, 고시문, 공청회 자료, 의회 의견청취, 보도자료**의 증거 수준을 동일하게 취급하지 않는다.
7. 정책자료·시의회 보고를 근거로 등록한 후속계획은 법정 효력을 확보한 확정계획이 아니다.

## 전국 확장 및 통합 구조

- 전국 자료는 행정구역별 JSON 파일을 계속 추가한다. `urban-plans` 브랜치에서만 작업한다.
- `related_plans.py`의 초기자료 선언에는 충북 JSON을 추가했다.
- 지역 선택 시 **충북 광역계획 → 각 시·군 계획**을 상속 조회하되 다른 시·군 고유계획을 혼합하지 않는다.
- 신규 `tests/test_chungbuk_plans.py`에는 11개 시·군 존재, 26개 계획·34개 링크, 조회 상속, 후속계획 상태 구분 검사를 추가했다.
- 후일 `urban-analysis`에 병합할 때 관련계획 관련 파일 변경분만 반영한다. `main` 및 배포 서버 변경은 이번에 하지 않는다.

## 추후 보강 필요

- 11개 시·군 기본계획의 후속 승인·변경 여부 확인
- 청주 외 시·군의 공업지역기본계획 수립 대상·현황
- 충주·제천·청주 등 정비기본계획, 노후계획도시정비기본계획 적용 유무
- 11개 시·군 도시재생전략계획 및 **활성화지역별 도시재생활성화계획**
- 시·군별 경관계획, 공원녹지기본계획, 주거종합계획, 교통정비계획
- 국토계획·중부권 광역교통·충청권 광역도시계획 등 충북 적용 상위계획
- 고시의 변경 이력, 원문 PDF·도면 제공 여부, 유효성 최종 검토

## 검증 구분

- JSON 및 GitHub 커밋과 테스트 추가는 실제 웹서버 실행과 별개다.
- PostgreSQL 운영 DB, 실배포 지도 화면과 FastAPI 통합 테스트는 수행하지 않았다.
- 공식 기관 링크에도 계획서 원본 미제공 또는 장별 요약본만 있는 경우가 있으므로 보고서 생성과 법정 판정의 근거로 자동 승격하지 않는다.
