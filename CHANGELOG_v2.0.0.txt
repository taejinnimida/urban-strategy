v2.0.0 — 서울 도시정비플랫폼 검토엔진 재설계

핵심
- 기존 후보선별 점수제 완전 제거.
- 사업방식 후보판정을 순차 하드게이트 방식으로 변경.

판정 순서
1. 목적사업
2. 법정 진입/사업대상/시행주체 하드게이트
3. 입지·면적·노후도·용도지역 등 법정 Rule Engine
4. 토지확보 방식
5. 의뢰·추진주체와 시행구조
6. 의제관계·실행경로
7. 최종 후보판정

최종 판정
- 우선검토:
  목적사업 직접 적합 + 법정진입 PASS + 법정 Rule PASS + 토지/주체 구조 적합
- 법정요건확인:
  목적사업 직접 적합이나 정량/입지 입력이 아직 REVIEW
- 시행구조확인:
  법적 후보지만 현재 토지확보/추진주체와 시행방식 조정 필요
- 진입조건확인:
  도시정비형 진입경로, 재건축 대상여부 등 구조 하드게이트 확인 필요
- 대안검토:
  목적사업의 보조/대안 제도
- 목적불일치 / 대상아님 / 조건미달:
  우선검토에서 제외

중요 하드게이트 유지
- 재건축:
  공동주택 재건축 대상이 아니면 대상아님
- 도심공공주택복합:
  공공 추진주체가 아니면 대상아님
- 도시정비형 재개발:
  기정 예정구역 / 정비가능구역 / 의제경로가 없으면 진입 불가
- 주거환경개선:
  공공 시행·공공협력 구조 확인

의제·실행경로
- 역세권활성화 → 도시정비형 재개발 정비예정구역 의제
- 역세권 장기전세 → 도시정비형 재개발 정비예정구역 의제
- 도시정비형 재개발의 모든 진입경로 trace
- 도심복합개발 20인 초과 시 신탁/위탁관리 REITs 경로
- 소규모주택정비 세부 대안/모아타운 연계

화면
- 후보 아이콘에 최종판정과 현재 판정단계를 표시
- 아이콘 클릭 시 ①~⑤ 검토 trace를 그대로 표시
- '법정 Rule Engine 결과'와 '최종 후보판정'을 분리
- 제도요건 PASS를 더 이상 자동으로 '우선검토'라고 부르지 않음
- analysisState.scheme_decisions에 최종판정/게이트/의제경로 저장

기존 데이터엔진 유지
- 필지/토지대장
- 건축물/건축HUB
- 역세권/중심지
- VWorld 도시계획 GIS
- 도시계획시설 즉시조회
- 11개 사업방식 상세 Rule Engine
